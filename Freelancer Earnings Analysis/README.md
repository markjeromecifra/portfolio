# Freelance Work Analysis Dashboard

## Insights
- App Development is the highest-earning category with an average earning of $5,201.45.
- Freelancers are balanced across platforms; Upwork leads slightly at 22%.
- Graphic Design is the most popular category with 265 freelancers, earning slightly below App Development at $5,136.87.
- SEO has the lowest average earnings among popular categories: $4,677.33.
